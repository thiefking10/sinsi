# 신시(神屍) 아트 가이드

> 버전 v0.2 / 2026-09-21
> 목적: 무료 에셋을 고르든, 직접 그리든, 외주를 주든 **같은 기준**으로 판단하기 위한 문서
> 관련 문서: `01-design-bible.md` (세계관, 적, 아이템 설정)

---

## 1. 한 줄 방향

**어둠 속에서 청동이 녹슬고, 신수가 푸르게 빛나고, 저주가 붉게 번지는 신화테크.**

단청의 색을 "화려한 장식"이 아니라 **어둠 속에서 빛나는 표식**으로 쓴다. 화면 대부분은 어둡고, 색은 의미가 있을 때만 켜진다.

---

## 2. 형식

| 항목 | 결정 | 이유 |
|---|---|---|
| 화풍 | **2D 픽셀 아트** | 초보자·소규모에 현실적, 폰에서 잘 보임, 인디 시장에서 검증됨 |
| 시점 | 탑다운 3/4 (약간 위에서 비스듬히) | 디아블로 계열 표준. 캐릭터 앞모습과 윗면이 함께 보임 |
| 바닥 타일 | **16 × 16 픽셀** | 그리기 쉽고 무료 에셋이 가장 많은 규격 |
| 확대 배율 | 폰 ×2, PC ×3 (**정수 배율만**) | 소수 배율은 픽셀이 뭉개짐 |
| 방향 | **4방향** (아래, 위, 옆 하나 그리고 좌우 반전) | 8방향 대비 작업량 절반 이하 |
| 광원 | **왼쪽 위** 고정 | 모든 에셋의 그림자 방향 통일 |
| 외곽선 | 가장 어두운 색(#120c0e) 1픽셀, 광원 쪽은 생략 가능 | 어두운 바닥 위에서 실루엣 확보 |
| 명암 | 재질당 3단계 (밝음, 기본, 그림자) + 외곽선 | 팔레트 절제 |

## 3. 크기 규격

캔버스 크기 기준. 실제 몸체는 캔버스보다 작게, **발끝 중앙이 기준점(피벗)**.

| 대상 | 캔버스 | 폰 화면 크기 (×2) | 비고 |
|---|---|---|---|
| 바닥 타일 | 16 × 16 | 32px | |
| 무당 (주인공) | 24 × 24 | 48px | 화면 높이의 약 12%. 이보다 크면 시야가 좁아짐 |
| 망령, 저주 뱉는 자 | 16 × 16 | 32px | 작고 떼로 나오는 적 |
| 돌진귀, 변이체, 부푼 자 | 24 × 24 | 48px | |
| 청동 껍데기 | 32 × 32 | 64px | |
| 보스 (동두 등 형제) | 64 × 64 | 128px | 주인공의 약 2.7배 |
| 원혼 | 16 × 16 | 32px | 반투명, 해방된 형제는 32 × 32 |
| 장애물 (뼈, 청동 돌기) | 16 × 16 ~ 32 × 32 | | |
| 단풍나무 | 32 × 48 | | 윗부분이 캐릭터를 가림 |
| 아이템 아이콘 | 16 × 16 | UI에서 ×3 | 등급색 테두리는 UI가 그림 |

### 애니메이션 프레임 (1단계 최소)

| 동작 | 프레임 | 속도 |
|---|---|---|
| 대기 | 4 | 6fps |
| 걷기 | 6 | 10fps |
| 공격(방울 흔들기) | 4 | 12fps |
| 피격 | 2 | 12fps |
| 쓰러짐 | 6 | 10fps |

적은 걷기 + 쓰러짐만 있어도 된다. 돌진귀는 "예고 자세" 2프레임, 부푼 자는 "부풀기" 4프레임 추가.

### 4.9 색의 약속 (반드시 지킬 것)

| 색 | 의미 | 금지 |
|---|---|---|
| **금빛** | 플레이어의 공격, 보상 | 적의 공격에 쓰지 않는다 |
| **밝은 신수** | 플레이어의 자원, 아군, 치유 | 적에게 쓰지 않는다 |
| **단풍 붉은색** | 저주, 위험, 적의 예고 | 플레이어 이펙트에 쓰지 않는다 |
| **독보라** | 적의 투사체 | 배경에 쓰지 않는다 (피할 대상이 묻힘) |

플레이어가 **색만 보고 0.2초 안에 "좋은 것인지 피할 것인지"** 알 수 있어야 한다.

### 4.10 가독성 규칙

- 캐릭터와 적은 바닥보다 **명도가 확실히 달라야 한다.** 흑백으로 바꿔도 구분되는지 확인한다.
- 바닥은 채도를 낮게, 캐릭터와 이펙트는 채도를 높게.
- 저주 단계가 오를수록 바닥이 어두워지므로, 적 실루엣은 가장 어두운 단풍숲 바닥에서도 보여야 한다.

### 4.11 UI 전용색 (36색과 별도)

세계관 팔레트(4.1~4.8)는 **게임 세계 안**의 사물에만 쓴다. 등급·상태 같은 **UI 기호**는 장르 관습을 따르는 별도의 색을 쓴다 — 세계관 색과 섞으면 오히려 "이건 세계관 색인가 UI 색인가" 헷갈린다.

## 5. 캐릭터 방향

### 5.1 무당

- **실루엣 핵심:** 넓게 퍼지는 무복 소매, 한 손의 방울, 다른 손의 부채. 머리에 전립(무관 모자) 또는 고깔.
- **색:** 흰 무복(백) + 붉은 쾌자(적) + 허리의 오방색 띠. 방울은 금빛.
- **공격 동작:** 방울을 앞으로 흔든다. 살풀이는 부채를 한 바퀴 휘두른다.
- **원혼:** 신수 광채색의 반투명 불꽃 형태. 얼굴은 그리지 않는다.

### 5.2 적

| 적 | 형태 키워드 | 주색 |
|---|---|---|
| 망령 | 떠다니는 흰 소복, 발이 없음, 까만 눈구멍 | 망령빛 |
| 돌진귀 | 앞으로 숙인 뿔 달린 짐승형, 몸이 앞을 향해 뾰족 | 성난 주홍 |
| 저주 뱉는 자 | 둥근 몸에 크게 벌어진 목구멍, 발사 전 목이 빛남 | 독보라 |
| 변이체 | 녹청 가시가 사방으로 돋은 몸 | 푸른 녹 |
| 부푼 자 | 핏줄이 선 혹덩어리, 터지기 전 부풀며 밝아짐 | 곪은 초록 |
| 청동 껍데기 | 무쇠 투구를 쓴 거구, 눈만 금빛으로 빛남 | 청동 + 무쇠 |
| 형제 (보스) | **구리 머리, 쇠 이마, 뿔.** 몸에 족쇄 조각이 박혀 있음 | 황동 + 무쇠 + 단풍 눈 |

형제 81명은 **같은 뼈대**(구리 머리 + 쇠 이마)에 무기·뿔 모양·족쇄 위치만 바꿔 변형한다. 작업량 관리의 핵심. (이 전략은 81명 전부를 만드는 쪽을 전제로 한다 — `01-design-bible.md` 3.3·12장에서 "전부 구현"로 확정.)

### 5.3 무속 표현 원칙

무속은 지금도 이어지는 한국의 살아 있는 신앙이다.
- 조롱하거나 공포의 대상으로만 그리지 않는다. 무당은 **공동체를 지키는 사람**으로 그린다.
- 실제 신당의 무신도나 특정 무속인의 모습을 그대로 베끼지 않는다.
- 상업 단계에서는 무속·국악 자문을 받는다.

## 6. 환경 방향

| 구역 | 바닥 | 장애물·소품 | 분위기 |
|---|---|---|---|
| 신시 변두리 (평온) | 흙, 뼈 조각이 박힌 땅 | 거대한 갈비뼈 기둥, 무너진 한옥 기와, 신수 등불 | 어둡지만 사람이 살던 흔적 |
| 저주 침식 | 녹청 균열이 번진 흙 | 솟아오른 청동 돌기, 녹슨 기계 잔해 | 금속이 병든 느낌 |
| 핏빛 단풍숲 (삼켜짐) | 핏빛 땅, 떨어진 단풍잎 | 단풍나무, 땅에 박힌 족쇄 사슬 | 아름답고 불길함 |

**1단계 최소 타일:** 구역별 바닥 4종(기본 3 + 변형 1), 경계 전환 타일, 장애물 3종씩.

## 7. 실제 유물 참고 (고증의 무기)

신시의 무기와 장비는 **한반도 청동기 유물**에서 모양을 가져온다. 다른 한국풍 게임이 조선에 집중하는 동안 신시만의 시각적 차별점이 된다.

| 유물 | 게임에서 |
|---|---|
| **팔주령** (여덟 방울이 달린 청동 방울) | 무당의 방울 기본형, 전설 방울 디자인 |
| **간두령, 쌍두령** (장대 끝·양쪽에 방울) | 방울 변형 |
| **다뉴세문경** (가는 선무늬 청동 거울) | 거울지기의 거울, 신수 기계의 문양 |
| **비파형 동검** (비파 모양 청동검) | 청동전사의 무기, 형제들의 무기 |
| 단청 문양 | UI 테두리, 신시 건축 |
| 솟대 | 신수 송신탑 |

국립중앙박물관 등의 공개 자료를 **모양 참고용**으로 쓰고, 사진을 그대로 에셋에 넣지 않는다.

## 9. 에셋 조달 기준

### 9.1 무료·유료 에셋을 고를 때

- [ ] **16px 타일 규격, 탑다운 3/4 시점**인가
- [ ] 라이선스가 **상업 이용 가능**인가 (CC0 우선, CC-BY면 크레딧 기록)
- [ ] 이 팔레트로 **색을 바꿔도 어색하지 않은가**
- [ ] 한 구역에 **서로 다른 작가의 팩을 2개 넘게 섞지 않았는가** (화풍 충돌)
- [ ] `ASSETS_CREDITS.md`에 출처와 라이선스를 기록했는가

### 9.2 AI 이미지 생성

- **컨셉 그림, 분위기 탐색 용도로만** 쓴다.
- 게임에 들어가는 최종 에셋으로는 쓰지 않는 것을 원칙으로 한다 (프레임 간 일관성 문제, 저작권 불확실성).
- 스팀은 AI로 만든 콘텐츠가 포함되면 출시 시 공개하도록 요구한다. 쓴다면 기록해 둔다.

### 9.3 외주를 줄 때

이 문서 전체 + 설계 문서의 적 목록 + 맛보기 게임 링크를 함께 전달한다. 첫 의뢰는 **무당 1명 + 망령 1종 + 바닥 타일 1세트**로 작게 시작해 화풍을 맞춘다.

5. 이펙트: 방울 파동, 원혼, 살풀이 부채, 폭발, 번개, 신수 방울
6. 보스 동두: 걷기·충격파·소환·해방
7. 아이템 아이콘: 부위 4종 × 기본형 4단계 = 16개 + 전설 8개
8. UI: 스킬 버튼 4개, 단청 문양 테두리

## 11. 클로드 코드용 기술 규격

- 파일: PNG, 투명 배경, 스프라이트 시트
- 이름 규칙: `종류_이름_동작_방향.png` (예: `char_mudang_walk_down.png`, `enemy_ghoul_walk.png`, `tile_curse_02.png`)
- 폴더: `assets/sprites/`, `assets/tiles/`, `assets/fx/`, `assets/icons/`, `assets/ui/`
- 기준점: 캐릭터와 적은 발끝 중앙
- Phaser 설정: `pixelArt: true` (픽셀이 흐려지지 않게), 카메라 배율은 정수
- 그래픽이 없는 동안에는 지금처럼 도형으로 그리되, **각 개체의 그리기 코드를 한 곳에 모아** 나중에 스프라이트로 교체하기 쉽게 한다

### 11.1 월드 단위 환산 (v0.2에서 실제 계산)

맛보기 프로토타입은 타일 68px 기준으로 만들어졌다. 최종 아트는 16px 타일이고, 폰은 ×2 배율(타일 32px 표시)이므로, **월드 단위는 "폰 기준 32px 타일"을 정식 기준으로 잡는다.** PC는 ×3(타일 48px)이지만 이건 카메라 확대율만 다른 것이고, 월드 단위(이동 속도·사거리 등 물리량) 자체는 폰/PC가 하나로 공유한다 — PC에서는 같은 세계가 더 크게 보일 뿐, 더 빨리 움직이지 않는다.

**환산 배율 = 32 / 68 ≈ 0.47**

`01-design-bible.md`의 실제 수치를 이 배율로 환산하면:

| 항목 | 68px 기준 (현재 프로토타입) | 32px 기준 (환산, ×0.47) |
|---|---|---|
| 월드 크기 (WS) | 1700 | 800 |
| 타일 크기 (TS) | 68 | 32 (정의값) |
| 무당 이동 속도 | 185 | 87 |
| 방울 투사체 속도 | 450 | 212 |
| 방울 사거리 (약) | 380 | 179 |
| 살풀이 범위 | 190 | 89 |
| 망령 속도 | 60 | 28 |
| 돌진귀 속도 / 돌진 속도 | 70 / 540 | 33 / 254 |
| 저주 뱉는 자 속도 / 구슬 속도 / 거리 유지 | 58 / 190 / 210~300 | 27 / 89 / 99~141 |
| 변이체 속도 | 92 | 43 |
| 부푼 자 속도 / 폭발 범위(자폭 · 처치) | 80 / 90 · 80 | 38 / 42 · 38 |
| 청동 껍데기 속도 | 46 | 22 |
| 보스 속도 / 충격파 반경 | 62 / 360 | 29 / 169 |

시간(초)·확률(%)·개수(관통 수, 최대 마리 수)는 화면 크기와 무관하므로 **환산하지 않는다.** 위 표는 "칸(타일) 몇 개를 가로지르는가"라는 체감은 그대로 두고, 픽셀 단위만 새 타일 크기에 맞춘 것이다 — 예를 들어 방울 사거리 380/68 ≈ 5.6칸이 179/32 ≈ 5.6칸으로 그대로 유지된다. 데이터 파일(`data/*.json`)에는 이 32px 기준 값을 넣는다.

- 월드 단위 조정: 위 표를 그대로 `data/` JSON 초기값으로 쓴다. 이후 수치를 조정하면 **이 표가 아니라 JSON이 정본**이 되고, 이 표는 "왜 이 초기값인지" 설명하는 근거로만 남긴다.
