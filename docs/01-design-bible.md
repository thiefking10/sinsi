## 1. 개요

### 1.1 한 줄

**찢긴 전쟁신 치우의 몸 위에 세운 도시에서, 번지는 저주를 막으며 형제들을 해방하는 액션 RPG.**

### 1.2 기본 정보

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 핵앤슬래시 ARPG (디아블로 계열) |
| 배경 | 한국 신화시대(배달·치우 시대)에서 영감받은 신화테크 판타지 |
| 1단계 | 웹 프로토타입, 혼자 폰으로 즐기며 다듬기 |
| 2단계 | 유료 패키지 (PC 스팀 우선, 이후 콘솔 검토) |
| 3단계 | 온라인 확장 |
| 수익 모델 | 구매형. 자동사냥·시간 판매형 과금 없음 |

### 1.3 포지셔닝 원칙

- **"한민족의 역사"가 아니라 "신화에서 영감받은 판타지"로 소개한다.** 치우를 조상으로 보는 해석은 주로 『환단고기』에서 오며, 주류 학계는 이를 후대의 위서로 본다. 중국도 치우를 자국 신화의 인물로 여긴다.
- 적 제국의 수장을 신화 속 **헌원(황제) 실명으로 쓰지 않는다.** 암시만 하고 가상의 이름을 쓴다.

### 1.4 시장 조사 요약 (2026-09 기준)

- **신의 시체 위의 도시**는 흔한 소재다 (D&D의 투나라스, 인디 TRPG 『The Valley of the Dead God』 등). 이것만으로 차별화되지 않는다.
- **치우 소재 상업 게임**은 사실상 없다 (2005년 모바일 『치우천왕전기』 정도).
- **한국 신화 대작이 늘고 있다**: 넥슨 『우치 더 웨이페어러』(전우치전), 매드엔진 『탈: 디 아케인 랜드』(가상의 조선, 2027), 크래프톤 『타래: 언바운드』. 모두 조선·고전소설 기반이며 배달·치우 시대 핵앤슬래시는 없다.
- **번지는 부패** 연출은 흔하지만 대부분 "되돌려서 세계를 회복"하는 구조다.

**차별점은 조합에 있다:** 되돌릴 수 없는 저주 + 찢긴 치우의 몸 + 배달 시대 신화테크 + 형제 해방. 여기에 **아트 방향의 청동기 유물 고증**(팔주령·비파형동검 등, `02-art-guide.md` 7장)이 시각적 차별점을 더한다 — 위 경쟁작이 전부 조선시대를 다루는 동안 신시만 그보다 훨씬 이른 시대의 실제 유물을 쓴다.

## 2. 세계관

### 2.1 핵심 설정: 신시(神市)는 신시(神屍) 위에 세워졌다

같은 소리, 다른 한자. 신화 속 환웅의 도시 신시(神市)는, 실은 쓰러진 신의 시체(神屍) 위에 세워진 도시다. 이 이중 의미가 제목이자 세계관의 뿌리다.

### 2.2 역사

1. 전쟁의 신 **치우**가 안개 너머의 세력과 **탁록**에서 싸웠다.
2. 치우는 패했다. 승자는 그의 몸을 **찢어 여러 곳에 흩었고**, 그를 묶었던 **족쇄에 저주**를 걸었다.
3. 사람들은 흩어진 몸 위에 도시를 세우고, 몸에서 **신수(神髓)**를 캐내 문명을 일으켰다.
4. 족쇄의 저주는 지금도 치우의 몸을 갉아먹고 있다. 저주가 번진 땅은 뒤틀리고, 끝내는 **핏빛 단풍숲**이 된다.

> 신화 근거: 치우가 패한 뒤 몸이 여러 곳에 나뉘어 묻혔다는 전승, 치우를 묶은 피 묻은 족쇄가 버려져 단풍나무숲이 되었다는 전승, 치우가 짙은 안개를 부렸다는 전승, 구리 머리 쇠 이마(銅頭鐵額)의 형제 81명.

### 2.3 신수와 신화테크

- **신수(神髓):** 치우의 몸에서 뽑아내는 푸른 발광 물질. 도시의 모든 동력원.
- 문명이 발달한 이유가 곧 신수다. 등불, 기계, 공중 누각이 신수로 돌아간다.
- **번영과 저주의 원인이 같다.** 신수를 과하게 캐낼수록 저주가 빨라진다 (후반 반전의 근거).
- 비주얼: 단청 색 + 황동·청동 기계 + 신수의 푸른 빛. 뼈 위에 올린 한옥 지붕의 고층 누각, 솟대 모양 송신탑, 전류가 흐르는 무당 방울. **"옛것"이 아니라 "우리가 모르는 다른 길로 발전한 고대".** (색·재질별 정확한 팔레트는 `02-art-guide.md` 4장)

### 2.4 치우

- **악역이 아니다.** 억울하게 찢긴 영웅이다. (한국 정서 반영, 확정)
- 저주를 정화하고 몸을 모을수록 치우가 되살아난다.
- 도시의 이름·유적·노래 곳곳에 치우를 기리는 흔적이 남아 있지만, 지배층은 이를 지우려 한다.

### 2.5 세력

| 세력 | 설명 | 역할 |
|---|---|---|
| **안개 너머의 제국** (가칭) | 치우를 찢고 저주를 건 승자. 남은 조각을 모아 신의 힘을 독차지하려 함 | 최종 적 |
| **풍백 가문** | 바람으로 저주의 독기를 빼내는 가문 | 도시 세력 |
| **우사 가문** | 비로 썩은 땅을 씻는 가문 | 도시 세력 |
| **운사 가문** | 구름과 안개로 도시를 바깥 세상에서 감추는 가문 | 배신자 후보 (안개를 다루므로 제국과 연결점이 자연스러움) |
| **곰족** | 동굴 시험을 버텨 신수에 적응한 지배층 | 도시 상층 |
| **범족** | 시험을 뛰쳐나가 저주받은 땅에서 살아남은 이들. 저주에 적응함 | 애매한 조력자 |
| **81형제** | 치우의 구리 머리 형제들. 저주에 먹혀 괴물이 됨 | 보스이자 해방 대상 |

### 2.6 도시를 감추는 안개

신시가 "미스터리 지역"인 이유. 운사 가문이 유지하는 안개 장막 때문에 바깥 세상은 신시의 존재를 모른다. 동시에 제국도 신시를 쉽게 찾지 못한다. 이 장막이 흔들리는 것이 3막의 계기다.

## 3. 이야기

### 3.1 한 줄 요약

찢긴 전쟁신의 몸 위에 세운 도시. 승자의 저주가 번지는 가운데, 치우의 조각을 품은 주인공이 형제들을 해방하고 흩어진 몸을 모아 설욕의 전쟁에 나선다.

### 3.2 주인공

- 몸에 **치우의 조각**을 품고 태어난 자. 저주가 아니라 **선택받은 증표**.
- **직업 = 품은 조각의 부위** (4장 참조). 직업 선택이 곧 이야기의 출발점이다.
- 흩어진 몸을 모을수록 강해진다. 성장과 서사가 같은 축이다.

### 3.3 81형제 해방 구조

- 형제들은 각 신체 부위를 지키며 저주에 먹혀 있다.
- 쓰러뜨리는 것은 **죽이는 것이 아니라 풀어주는 것**이다.
- 해방된 형제는 **넋으로 남아 주인공과 함께 싸운다.** 보스를 잡을수록 동료가 늘어난다.
- 프로토타입 v4에서 첫 번째 형제 **동두(銅頭)** 로 구현됨.
- **제작 전략(확정, `02-art-guide.md` 5.2):** 81형제는 전부 구현하는 쪽으로 아트 파이프라인이 이미 설계됐다 — **같은 뼈대**(구리 머리 + 쇠 이마)에 무기·뿔 모양·족쇄 위치만 바꿔 변형하는 방식. 이 전략이 성립하려면 81명 전부를 만드는 방향이 전제이므로, 12장의 "81형제 수" 항목은 **전부 구현**으로 사실상 확정된 것으로 본다. 단, 몇 명을 "핵심 형제"(개별 성격·보스 패턴)로 깊게 만들고 나머지를 "정예"(같은 뼈대 + 얕은 변형 패턴)로 가볍게 만들지의 **비율**은 여전히 열려 있다.

### 3.4 막 구성 (초안)

| 막 | 무대 | 핵심 사건 |
|---|---|---|
| 1막 | 신시 변두리 | 첫 형제 해방, 팔의 조각 회수. 저주의 정체가 족쇄라는 단서 |
| 2막 | 핏빛 단풍숲 | 족쇄의 숲. 범족과의 만남, 승자가 기록하지 않은 다른 역사 |
| 3막 | 안개 너머 탁록 | 옛 전장. 안개 장막이 흔들리고 제국군이 침공 |
| 4막 | 신단수 | 도시 중심의 채굴탑. 운사 가문의 배신, 치우의 심장 |
| 5막 | 머리 | 흩어진 몸이 모이고 치우가 일어선다. 제국과의 최후 결전 |

## 4. 직업

### 4.1 직업 목록

| 직업 | 품은 조각 | 전투 방식 | 디아블로 대응 | 도입 단계 |
|---|---|---|---|---|
| **무당** | 목소리 | 방울 원거리, 원혼 소환, 저주를 억제하며 싸움 | 강령술사 | **1단계 (구현됨)** |
| **청동전사** | 팔 | 비파형 동검 근접(부채꼴 베기), 분노 자원, 저주가 높을수록 강해짐 | 야만용사 | **2단계 (구현됨, 협동 프로토타입)** |
| 신궁 | 눈 | 빠른 활 원거리 | 아마존/도적 | 2단계 |
| 풍백술사 | 숨 | 바람·비·구름 원소 마법 | 원소술사 | 3단계 |
| 범족 사냥꾼 | 피 | 호랑이 변신 | 드루이드 | 3단계 |
| 거울지기 | 심장 | 청동 거울·방패, 빛 반사와 정화 | 성기사 | 3단계 |

> 원칙: 직업 하나 추가 = 스킬, 연출, 밸런스 전부 추가. 한 번에 하나씩, 이전 직업이 재밌다고 확인된 뒤에 추가한다.

### 4.2 무당 상세 (프로토타입 v4)

**기본 능력치:** 체력 100, 이동 속도 185, 치명타 확률 15%, 치명타 피해 ×2

| 기술 | 효과 | 수치 |
|---|---|---|
| **방울** | 가장 가까운 적에게 금빛 소리 파동 발사. 누르고 있으면 연속 | 피해 13, 간격 0.38초, 속도 450, 관통 2, 사거리 약 380 |
| **초혼** | 모은 넋만큼 원혼 소환 | 대기 1.5초. 원혼: 피해 9, 공격 간격 0.5초, 지속 20초, 최대 8기 |
| **살풀이** | 주변 적에게 저주 | 범위 190, 대기 8초, 피해 10. 저주 5초: 이동 50% 감소, 받는 피해 ×1.5 |
| **정화** | 신수를 써서 구역 저주 감소 | 저주 −18. 비용 4에서 시작, 쓸 때마다 +2 |

- **넋:** 적을 쓰러뜨릴 때마다 1개 (보스 제외). 최대 8개.
- **자동 방울:** 켜면 적이 사거리 안에 있을 때 자동 발사 (반자동 편의 기능, 9장 참조).

> 위 수치를 16px 타일 기준 최종 아트 스케일로 환산한 표는 `02-art-guide.md` 11장에 있다.

### 4.3 레벨업 강화 (무당)

필요 경험치: `9 + (레벨 − 1) × 6`. 레벨업 시 게임이 멈추고, 아래 중 최대치에 도달하지 않은 3개가 무작위 제시된다.

> v4의 `5 + (레벨−1)×4`는 몬스터 처치 경험치(1~4)에 비해 낮아서 초반 레벨업이 몰아치듯 떴다("샘플이라 빠른 게 아니라 그냥 두 수치가 우연히 그렇게 맞물린 것"). v5에서 위 값으로 올려 체감 속도를 늦췄다.

| 이름 | 효과 | 최대 |
|---|---|---|
| 갈래 방울 | 방울이 한 갈래씩 더 퍼짐 (간격 0.22rad) | 3 |
| 빠른 장단 | 방울 속도 +20% | 4 |
| 울림 | 방울 피해 +25%, 관통 +1 | 3 |
| 넋 그릇 | 넋 최대치 +3, 원혼 최대 +2, 원혼 피해 +25% | 3 |
| 원혼 폭발 | 원혼이 사라질 때 폭발 (범위 70, 피해 25 × 단계) | 3 |
| 머무는 넋 | 원혼 지속 +8초 | 2 |
| 부르지 않아도 | 넋이 가득 차면 자동 초혼 | 1 |
| 넓은 부채 | 살풀이 범위 +30%, 대기 −1.5초 | 3 |
| 넋 불씨 | 저주 걸린 적 처치 시 넋 +1 | 1 |
| 넋 흡혈 | 원혼 타격 시 15%×단계 확률로 체력 +2 | 2 |
| 신령의 가호 | 최대 체력 +25, 완전 회복 | 3 |
| 신수 감각 | 신수 흡수 반경 +60%, 신수 드랍 +30% | 2 |
| 날랜 발 | 이동 속도 +12% | 2 |

전부 최대치면 "숨 고르기"(완전 회복)가 제시된다.

## 5. 핵심 시스템: 족쇄의 저주

### 5.1 원칙

- **저주는 막을 수 없다. 늦추고, 어디를 버릴지 고를 뿐이다.**
- 정화 비용이 계속 올라가므로 결국 삼켜진다. 이것은 버그가 아니라 설계다.
- **삼켜짐은 벌이자 보상이어야 한다.** 순수한 벌이면 플레이어는 포기하고, 순수한 보상이면 정화 시스템이 죽는다.

### 5.2 단계

| 단계 | 저주 수치 | 연출 | 게임플레이 변화 |
|---|---|---|---|
| 평온 | 0 ~ 25 | 흙·뼈 바닥 | 망령, 돌진귀 |
| 징후 | 26 ~ 50 | 한쪽 구석부터 녹청빛으로 물듦 | 저주 뱉는 자, 변이체 추가 |
| 침식 | 51 ~ 85 | 뼈 기둥 40% 무너짐, 청동 돌기 8개 솟음 | 부푼 자, 청동 껍데기 추가 |
| 전화 임박 | 86 ~ 99 | 화면 가장자리 어두워짐 | 장단 최고속 |
| 저주에 삼켜짐 | 100 | 맵 전체가 핏빛 단풍숲으로 재생성, 단풍잎 낙하 | 되돌릴 수 없음. 신수 ×2, 적 체력 ×1.3, 3.2초 뒤 보스 |

- 자연 상승 속도: 초당 `0.55 + 0.25 × 단계` (단계 최대 3으로 계산)
- 정화 없이 평온 → 삼켜짐까지 약 2분

### 5.3 예정된 변경

- **정화를 버튼에서 행동으로:** 맵에 나타나는 "저주의 샘"을 일정 시간 지키며 버티는 이벤트로 바꾼다. "어디로 갈지" 판단을 만든다.
- **여러 구역:** 본 게임에서는 치우의 신체 부위별로 구역이 나뉘고, 도시 화면에서 어느 구역에 신수를 쓸지 고른다 (`00-onepager.md`의 코어 루프). **이 다구역 시스템은 아직 코드로 검증되지 않았다** — `00-onepager.md` 8장의 R1~R5가 이 부분의 기술 리스크이며, 현재 전부 미검증 상태다. 본 개발 착수 전에 반드시 별도 수직 슬라이스로 먼저 찔러봐야 한다.

## 6. 전투와 적

### 6.1 적 목록

적 체력은 시간에 따라 `× (1 + 경과초 / 240)`, 삼켜진 구역에서 추가 ×1.3.

| 이름 | 등장 | 체력 | 속도 | 접촉 피해 | 행동 |
|---|---|---|---|---|---|
| 망령 | 평온 | 22 | 60 | 8 | 걸어옴. 35% 확률로 4마리 무리 |
| 돌진귀 | 평온 | 34 | 70 | 14 | 250 이내에서 멈추고 0.62초간 붉은 점선 예고 → 0.42초 돌진(속도 540, 피해 ×1.3). 재사용 2.8초 |
| 저주 뱉는 자 | 징후 | 28 | 58 | 6 | 210~300 거리 유지하며 선회. 입이 0.45초 빛난 뒤 보라 구슬 발사(속도 190, 피해 10). 재사용 2.4초 |
| 변이체 | 징후 | 48 | 92 | 12 | 빠르게 추격 |
| 부푼 자 | 침식 | 30 | 80 | 6 | 50 이내에서 0.7초 부풀다 폭발(범위 90, 플레이어 22, 적 40). 먼저 잡으면 적에게만 폭발(범위 80, 피해 40) |
| 청동 껍데기 | 침식 | 95 | 46 | 18 | 느리고 단단함 |

### 6.2 출현

- 간격: `max(0.28, 1.4 − 단계 × 0.26 − 경과초 / 600)`초
- 동시 최대: 38마리 (삼켜진 뒤 50)
- 처음 15초는 망령만

### 6.3 보스: 저주에 먹힌 형제, 동두

- 체력 1500, 속도 62, 접촉 피해 24, 밀려남 저항 88%
- 3.2초마다 충격파 (반경 360까지 퍼짐, 닿으면 16)
- 7초마다 망령·돌진귀 4마리 소환
- 쓰러뜨리면 **해방**: 금빛 넋으로 남아 함께 싸움 (피해 30), 전설 1 + 희귀 2 확정 드랍

### 6.4 타격감 요소

- 치명타: 큰 노란 숫자와 느낌표, 밀어내기 ×1.8
- 짧은 멈춤(히트스톱): 망령 외 적 처치 0.03초, 피격 0.05초, 보스 해방 0.3초
- 처치 시 흰 고리 + 파편, 화면 흔들림
- 체력 30% 이하: 화면 가장자리 붉은 맥박
- 적 머리 위: 저주(붉은 점선 고리), 불탐(주황 불꽃)

## 7. 아이템

### 7.1 부위와 기본형

저주 단계에 따라 기본형 이름이 올라간다.

| 부위 | 기본형 (단계별) | 고정 능력치 |
|---|---|---|
| 방울 | 낡은 → 놋쇠 → 청동 → 신령 방울 | 방울 피해 |
| 부채 | 종이 → 비단 → 오방 → 신령 부채 | 살풀이 범위 |
| 무복 | 삼베 → 무명 → 비단 → 신령 무복 | 최대 체력 |
| 노리개 | 나무 → 옥 → 산호 → 신령 노리개 | 치명타 확률 |

시작 장비: 낡은 방울 (방울 피해 +5%)

### 7.2 등급

| 등급 | 색 | 추가 능력치 | 분해 시 신수 | 이름 |
|---|---|---|---|---|
| 일반 | 하양 | 0 | 1 | 기본형 이름 |
| 마법 | 파랑 | 1~2 | 2 | 접두어 + 기본형 (예: 예리한 옥 노리개) |
| 희귀 | 노랑 | 3~4 | 4 | 무작위 조합 (예: 안개의 한) |
| 전설 | 주황 | 2~3 + 고유 효과 | 8 | 고유 이름 |

> 이 4색(하양/파랑/노랑/주황)은 `02-art-guide.md`의 36색 세계관 팔레트와는 별도인 UI 전용색이다 (장르 관습). 상세는 `02-art-guide.md` 4.11.

등급 확률 (단계 s, 삼켜짐 = 4):
- 전설: `3% + s × 1%` (삼켜진 뒤 +2%)
- 희귀: 누적 `17% + s × 3%`까지
- 마법: 누적 50%까지
- 나머지 일반

### 7.3 추가 능력치 13종

수치는 `최솟값~최댓값 × (1 + 단계 × 0.25)`.

| 능력치 | 범위 | 마법 접두어 |
|---|---|---|
| 방울 피해 % | 8~20 | 날선 |
| 방울 속도 % | 5~12 | 재빠른 |
| 원혼 피해 % | 10~25 | 원한 서린 |
| 원혼 지속 초 | 2~5 | 오래가는 |
| 최대 체력 | 10~25 | 든든한 |
| 치명타 확률 % | 2~5 | 예리한 |
| 치명타 피해 % | 15~40 | 잔혹한 |
| 이동 속도 % | 3~8 | 날랜 |
| 넋 최대치 | 1~2 | 넋 담긴 |
| 살풀이 대기 감소 % | 6~15 | 바람 든 |
| 신수 획득 % | 10~25 | 신수 머금은 |
| 초당 체력 회복 | 0.5~1.5 | 숨 고르는 |
| 살풀이 범위 % | 8~18 | 넓은 |

### 7.4 전설 8종

| 이름 | 부위 | 효과 |
|---|---|---|
| 천둥 방울 | 방울 | 방울 적중 시 20% 확률로 번개가 3명에게 연쇄 (방울 피해의 80%) |
| 넋부름 방울 | 방울 | 방울로 쓰러뜨린 적은 넋 +1 |
| 핏빛 단풍 부채 | 부채 | 살풀이에 걸린 적이 5초간 0.5초마다 불탐 (방울 피해의 45%) |
| 풍백의 부채 | 부채 | 살풀이 밀어내기 ×3, 대기 −30% |
| 오방신장 무복 | 무복 | 피해를 받으면 원혼 2기 소환 (지속 8초, 재사용 3초) |
| 범가죽 무복 | 무복 | 체력 30% 이하일 때 모든 피해 +60% |
| 찢긴 족쇄 | 노리개 | 저주 걸린 적이 쓰러지면 폭발 (범위 65) |
| 동두의 이마쇠 | 노리개 | 원혼 최대 수 절반, 원혼 피해 ×2.2, 크기 증가 |

**의도된 조합 예시:** 찢긴 족쇄 + 핏빛 단풍 부채 + 넓은 부채 (저주 폭발형) / 동두의 이마쇠 + 넋 그릇 + 머무는 넋 (거대 원혼형) / 천둥 방울 + 갈래 방울 + 빠른 장단 (탄막형)

### 7.5 드랍과 가방

- 드랍 확률: 망령 3%, 돌진귀·저주 뱉는 자·변이체 7%, 부푼 자 6%, 청동 껍데기 18%. 삼켜진 뒤 ×1.5
- 위를 지나가면 자동 획득. 가방 12칸, 가득 차면 바닥에 남음
- 가방 화면: 게임 정지. 초록 ▲ = 현재 장비보다 좋음 (능력치 가중 점수 비교, 전설 +45점)
- 장착, 해제, 분해, "일반·마법 모두 분해"
- **분해한 신수는 정화에 쓸 수 있다.** "장비를 챙길까, 녹여서 구역을 지킬까"가 핵심 고민

## 9. 자동 시스템 방침 (확정)

### 9.1 결정

- **완전 자동사냥은 넣지 않는다.**
- "직접 1시간 = 자동 1시간" 같은 시간 교환 방식도 넣지 않는다.

### 9.2 이유

1. 구매형 게임의 플레이어는 직접 조작하는 손맛을 산다. 자동 전투는 모바일 방치형으로 오해받는다.
2. 핵심 재미("어디를 버릴지", "언제 정화할지")를 자동이 건너뛰게 된다.
3. 자동 시간 제한은 과금 장치로 의심받는다.
4. 나중에 추가하는 것은 자연스럽지만, 넣었다가 빼면 반발이 크다.

### 9.3 유지하는 것

- **자동 방울 (반자동):** 편의·접근성 기능. 이동과 판단은 직접.
- **부르지 않아도 (강화):** 빌드 선택으로 얻는 자동 초혼.

### 9.4 향후 후보: 형제 원정

- 해방한 형제의 넋을 **이미 삼켜진 구역**으로 보내, 게임을 끈 동안 신수와 장비를 가져오게 한다.
- 새 구역과 보스는 반드시 직접 플레이.
- **보상 상한 필수.** 온라인 확장 시 무제한 자동은 작업장(봇)과 시세 붕괴를 부른다.
- 지금 할 일: "해방한 형제 목록"과 "삼켜진 구역 목록"을 저장 데이터로 남겨두기만 한다.

## 10. 조작과 화면 (모바일)

- **가로 모드 기본.** 세로로 들면 회전 안내가 뜨고 게임이 멈춘다 ("세로로 계속하기" 선택 가능). 안드로이드는 시작 시 전체 화면 + 가로 고정 시도, 아이폰은 브라우저 제한으로 직접 회전.
- 왼쪽 위: 저주 단계와 수치, 체력, 신수, 레벨·경험치
- 오른쪽 위: 가방(좋은 장비 개수 표시), 자동 방울, 소리
- 하단 중앙: 보스 체력
- 왼손: 화면 아무 곳이나 끌어서 이동 (떠다니는 조이스틱)
- 오른손: 방울(큰 버튼), 초혼(넋 개수, 가득 차면 푸른 테두리), 살풀이(대기 시간 원형 표시), 정화(비용 표시)
- 노치 영역 회피: 모든 고정 요소에 안전 영역 여백 적용
- 키보드(데스크톱 테스트용): WASD 이동, J/Space 방울, K 초혼, U 살풀이, L 정화, I 가방
